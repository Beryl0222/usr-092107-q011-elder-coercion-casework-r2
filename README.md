# 涉老强迫交易线索网

本仓库记录区级涉老权益中心"线索协同与案件证据后端"已确认的领域对象、事件名称和基础校验方式，便于公安、社区、银行、检察等系统交换一致的数据。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型、事件名称与来源/载荷字段词汇。
- `data/sample.json`：一条用于本地联调的中文样例。
- `data/flow.sample.json`：一条完整办案链的中文样例（接报去重 → 人车商户 → 模型提示/人工确认排除 → 口述与补正 → 视频与鉴定封存 → 银行紧急联络与资金控制 → 跨区并案 → 司法移送 → 追缴进度 → 分级授权 → 社区公告）。
- `src/`：事件信封的最小校验代码（`validate_event` 校验单条，`validate_stream` 校验事件流）。
- `tests/`：验证样例符合基础约定，并覆盖每条法定边界规则。

## 记录与边界原则

- **只追加、不原地改写**：记录一经接收，标识、发生时间与版本不得改写；同一聚合版本连续递增；受害人口述的补充与更正使用 `STATEMENT_AMENDED` 后继事件，原始版本与每次 `*_ACCESSED` 调阅记录均保留。
- **来源留存与去重**：任何记录（含风险模型提示）都必须携带 `source.channel` 与来源系统原始单号；同一事件按仓库事件标识以 `REPORT_DEDUPED` 去重，原始来源不丢失。
- **模型只提示、不定罪**：`LINK_SUGGESTED` 仅由风险模型或人工研判产生；确认（`LINK_CONFIRMED`）必须有人工确认人；已排除的关联以 `LINK_REJECTED` 保留排除理由，不删除。
- **紧急处置与资金控制**：`EMERGENCY_CONTACT_STARTED` 须记录值班员与法定权限依据；冻结（`FUND_CONTROL_DECIDED`）须人工批准人与法律依据；仅凭 `SIMILAR_TRANSACTION_ONLY`（普通相似交易）不得冻结，模型提示不得自动触发冻结。
- **证据保管链**：`EVIDENCE_SEALED` 必须记录取得方式、保管人、使用范围；跨区 `CASE_MERGED` 引用的每份证据须先行封存且三要素齐全，调阅须登记调阅人、事由与使用范围。
- **角色回看网络**：`SUBJECT_ROLE_NOTED` 记录嫌疑人角色（搭讪、司机、看守施压、收银、推销等）并通过 `network_refs` 回看共同作案网络。
- **分级授权**：社工仅取得保护老人所需字段（联系方式、保护需求、紧急状态、服务计划）；老人及家属仅查询受理状态与财物追缴进度。
- **公开公告脱敏**：`RISK_NOTICE_PUBLISHED` 必须为公开级，不得携带未公开案情、嫌疑人真实姓名、口述原文或封存证据。

个人、机构及商业敏感信息仅向履行职责所需的调用方开放。
